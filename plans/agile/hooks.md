## Why none of these runs automatically

Every command above is read-only or local, so running them would be cheap — and
that is exactly the trap. A hook that fires on its own trains the maintainer to
stop reading what it printed. The agent proposes, shows the command verbatim,
and waits; the approval is where the attention is.

The one exception is already outside this file: `husky` + `lint-staged` run
`eslint --fix` and `prettier --write` on staged files. They are a convenience,
not the gate (`definition-of-done.md`), and they can only reformat — they cannot
pass a failing check.
